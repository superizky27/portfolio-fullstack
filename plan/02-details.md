# 02 - RTCC-O Framework

## R — Role
Berperan sebagai backend-oriented developer yang fokus pada clean architecture, modular design, dan API-driven development.

---

## T — Task
Membangun aplikasi portfolio berbasis web yang:
- Menampilkan informasi profil dan project
- Menggunakan API untuk data dinamis
- Memiliki struktur code yang rapi dan mudah dikembangkan

---

## C — Context
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js (Express)
- Data: JSON (sebagai database sementara)
- Target: Recruiter dan Technical Reviewer

---

## C — Constraints
- Menggunakan semantic HTML (tidak berlebihan memakai div)
- Tidak menggunakan framework frontend
- Code harus readable dan modular
- Data project tidak boleh hardcoded di frontend
- Wajib menggunakan API (fetch)
- Output AI harus direview dan diperbaiki secara manual

---

## O — Output
- Website portfolio yang responsive
- REST API endpoint (`/projects`)
- Data ditampilkan secara dinamis dari backend
- Struktur folder yang jelas dan modular

---

## 🧠 Perspektif Engineering
Pendekatan ini mencerminkan prinsip backend:
- Separation of concerns
- Modular design
- API-driven architecture
- Scalability
