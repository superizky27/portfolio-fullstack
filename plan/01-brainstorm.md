# 01 - Brainstorming

## 🎯 Tujuan Project
Membangun website portfolio sederhana yang menampilkan profil dan project dengan pendekatan backend-oriented (terstruktur dan scalable).

---

## 👥 Target User
- HR / Recruiter
- Technical Reviewer
- Hiring Manager (entry-level backend role)

Tujuan utama:
Memudahkan mereka memahami profil dalam waktu singkat (≤10 detik scanning).

---

## 🧩 Fitur Utama
- Hero section (perkenalan singkat)
- About section (latar belakang & minat)
- Project section (data diambil dari backend API)
- Contact section

---

## 🎨 Pendekatan UI / Desain
- Desain minimalis dan clean
- Fokus pada keterbacaan (readability)
- Menghindari visual yang terlalu kompleks

Alasan:
Recruiter lebih fokus ke informasi dibanding tampilan visual yang berlebihan.

---

## 🤖 Peran AI
AI digunakan untuk:
- Generate struktur awal HTML & CSS
- Memberikan ide layout
- Membantu mempercepat proses development

---

## 🧠 Evaluasi Output AI
Kekurangan hasil AI:
- Tidak menggunakan semantic HTML secara optimal
- Terlalu banyak penggunaan `<div>`
- Struktur tidak modular
- Styling kurang konsisten

---

## ✅ Perbaikan yang Dilakukan
- Menggunakan semantic HTML (`header`, `section`, `footer`)
- Menyederhanakan struktur HTML
- Memisahkan UI dan logic
- Menghubungkan frontend dengan backend API

---

## 💡 Insight
AI membantu mempercepat development, tetapi tetap membutuhkan analisis dan perbaikan manual agar code tetap clean dan scalable.
